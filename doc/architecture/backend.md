# Backend Rust

Le backend est local. Il n’expose pas de serveur HTTP ; la fenêtre communique par IPC Tauri et le pont MCP par un socket Unix.

## Modules

| Module | Rôle |
|---|---|
| `storage.rs` | Dossier de configuration, écritures atomiques, workspace, grants de chemins. |
| `extensions.rs` | Paquets importés, sources/dépôts, index, zip, validation, état d’installation. |
| `settings.rs` | `settings-v1.json`. |
| `markdown.rs` | Sélection, lecture et écriture de fichiers Markdown, grants. |
| `explorer.rs` | Sélection de dossier, listage, ouverture Markdown, grants. |
| `terminal/` | Sessions PTY, entrée/sortie, redimensionnement, zsh. |
| `preview.rs` | Fichiers locaux, cache des liens, classification et validation pour l’Aperçu. |
| `web.rs` | Vues web natives par tuile, navigation, boîte, texte extrait. |
| `mcp/` | Socket local, clients, messages JSON-RPC. |
| `agents.rs` | Détection et configuration des clients MCP connus. |
| `window.rs` | Matériau de fenêtre macOS. |
| `bin/spark-mcp.rs` | Sidecar MCP minimal qui relaie vers la fenêtre. |

## Commandes Tauri

Toute commande est déclarée trois fois : `lib.rs` (`generate_handler!`), `build.rs` (`AppManifest::commands`) et `capabilities/main.json`. Les permissions sont générées par le build dans `src-tauri/permissions/autogenerated/`.

Groupes :

- Workspace : `workspace_load`, `workspace_save`.
- Réglages : `settings_load`, `settings_save`.
- Extensions : `extension_list`, `extension_install`, `extension_remove`, `extension_install_zip`, `registry_fetch`, `extension_sources`, `extension_source_add`, `extension_source_remove`.
- Markdown : `markdown_select`, `markdown_confirm_close`, `markdown_read`, `markdown_write`.
- Explorateur : `explorer_select`, `explorer_list`, `explorer_open_markdown`, `explorer_directory`.
- Terminal : `terminal_start`, `terminal_input`, `terminal_resize`, `terminal_close`.
- Aperçu : `preview_select`, `preview_source`, `preview_from_explorer`, `preview_drop`, `preview_fetch`, `preview_probe`.
- Navigateur : `web_open`, `web_bounds`, `web_snapshot`, `web_show`, `web_appearance`, `web_navigate`, `web_history`, `web_reload`, `web_close`, `web_read_text`.
- Notifications : `notify_desktop`, adossé à `tauri-plugin-notification`.
- Menu de tuile : `popup_tile_menu`, menu du système pour le déplacement.
- MCP et agents : `mcp_reply`, `mcp_notify`, `mcp_cache_tools`, `mcp_link`, `agent_setup`, `agent_connected`.
- Fenêtre : `set_window_material`, `set_window_theme`.

## Stockage local

Le dossier est `app_config_dir()`, soit sur macOS `~/Library/Application Support/fr.spark.desktop/`.

| Fichier/dossier | Contenu |
|---|---|
| `workspace-v1.json` | Espace, onglets, tuiles, disposition, état par extension. |
| `workspace-recovery.json` | Copie de secours créée lors d’une reprise. |
| `settings-v1.json` | Préférences applicatives. |
| `extensions.json` | Extensions installées, versions, sources et dépôts. |
| `extensions/<id>/<version>/` | Paquets importés extraits. |
| `markdown-access.json` | Grants de fichiers Markdown. |
| `explorer-access.json` | Grants de dossiers. |
| `preview-access.json` | Grants de fichiers ouverts par l’Aperçu. |
| `run/mcp.sock` | Socket MCP local. |
| `run/tools.json` | Cache d’outils MCP pour les clients. |
| cache applicatif `preview/<id>.bin` | Fichiers téléchargés pour l’Aperçu (PDF, images, textes). |
| cache applicatif `web/profile/` | Profil du webview sous Windows et Linux ; macOS utilise `~/Library/WebKit/<identifiant>/`. |
| cache applicatif `web/text/<tuile>.txt` | Texte de page extrait pour un agent. |

Le dossier `fr.lab.desktop` de l’ancienne identité est repris au premier lancement si `fr.spark.desktop` n’existe pas encore. Les fichiers existants ne sont jamais écrasés.

## Extensions importées

- Les manifestes sont validés côté Rust : schéma 2, identifiant non réservé, version `x.y.z`, fichiers relatifs, type de tuiles préfixé par l’id, captures, pas de certification déclarée.
- Les chemins absolus, `..`, les liens symboliques, `.git` et `node_modules` sont refusés ou ignorés.
- Limites : 256 Kio de manifeste, 400 fichiers, 25 Mio décompressés, profondeur 8, 20 types de tuiles, 8 captures.
- Un zip est limité à 30 Mio, vérifié par SHA-256 avant extraction.
- L’installation est atomique : staging puis renommage. L’état `extensions.json` est écrit après succès.
- Les URL sont HTTPS en release ; `http://127.0.0.1` et `http://localhost` sont tolérés en debug pour les dépôts de test.

Voir [le format du paquet](../extensions/package.md), [les dépôts](../extensions/registry.md) et [le modèle de confiance](../security/trust-model.md).

## MCP

Le pont est décrit dans [le pont MCP](mcp.md). Le sidecar `spark-mcp` est un binaire externe déclaré dans `tauri.conf.json` et reconstruit par `npm run sidecar`.

## Réseau et CSP

Le CSP autorise :

- `script-src`, `style-src`, `font-src` et `img-src` depuis `asset:` et `http://asset.localhost` ;
- `connect-src` vers l’IPC Tauri et `https://api.openalex.org`.

Le protocole `asset` est limité au cache de l’Aperçu, aux anciens caches PDF et OpenAlex, et à `$APPCONFIG/extensions/**`. Une extension importée n’a pas de CSP séparée : ses scripts et styles sont chargés dans la page principale. Voir [Tauri](../operations/tauri.md).
