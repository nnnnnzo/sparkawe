# Tauri

## Commandes

Une commande doit être déclarée trois fois :

1. `src-tauri/src/lib.rs`, dans `generate_handler!` ;
2. `src-tauri/build.rs`, dans `AppManifest::commands` ;
3. `src-tauri/capabilities/main.json`, en `allow-<nom-en-kebab-case>`.

Les permissions sont générées par le build dans `src-tauri/permissions/autogenerated/`. Oublier un des trois endroits fait échouer l’`invoke` à l’exécution, pas à la compilation.

Commandes actuelles : voir [le backend](../architecture/backend.md#commandes-tauri).

## Fenêtres et capabilities

- Une seule fenêtre `main`.
- `capabilities/main.json` couvre le workspace, les réglages, le PDF, le MCP, les agents, les extensions.
- `capabilities/markdown.json`, `explorer.json` et `terminal.json` ajoutent les commandes de leurs modules à la fenêtre `main`.
- Toutes les extensions importées s’exécutent dans `main` : elles partagent cette surface de permissions.

## CSP

`tauri.conf.json` autorise :

- `script-src`, `style-src`, `font-src`, `img-src` depuis `asset:` et `http://asset.localhost` ;
- `connect-src` vers l’IPC Tauri et `https://api.openalex.org` ;
- `worker-src 'self' blob:` pour pdf.js.

Une extension importée charge son bundle et son CSS par le protocole `asset`. Il n’y a pas de CSP séparée par extension.

## Protocole asset

`assetProtocol.scope` :

```json
[
  "$APPCACHE/pdf/**",
  "$APPCACHE/openalex/**",
  "$APPCONFIG/extensions/**"
]
```

Le scope extensions permet de charger les paquets importés. `convertFileSrc` produit l’URL utilisée par le loader.

## Sidecar MCP

- `spark-mcp` est déclaré dans `externalBin`.
- `npm run sidecar` le reconstruit en debug ; `npm run sidecar:release` pour la distribution.
- Le socket et le cache d’outils vivent dans `run/`.

## Dialogue

`tauri-plugin-dialog` est initialisé. Le Store utilise le sélecteur de dossier de l’Explorateur (`explorer_select`) pour le bouton **Parcourir** de l’import local.

## Changement natif

Un changement Rust déclenche un rebuild et un redémarrage par le watcher. La fenêtre et les sessions terminal sont fermées. Demander l’accord avant, fermer proprement, puis laisser une seule instance.

## Checklist d’une commande

- [ ] fonction dans le module Rust ;
- [ ] `generate_handler!` ;
- [ ] `AppManifest::commands` ;
- [ ] capability `allow-<nom>` ;
- [ ] types d’entrée/sortie sérialisables ;
- [ ] validation des entrées et limites ;
- [ ] test Rust si la logique est non triviale ;
- [ ] documentation backend et opérations mise à jour.
